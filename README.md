# PROG8245 Lab Submissions

 **Lab1**

This project collects and cleans a sales dataset for exploratory analysis and reporting in a machine learning and data programming course. It demonstrates practical data collection, preprocessing, validation, and enrichment steps using real-world-style transactional data.

The repository was created to support learning in data cleaning, transformation, and lightweight analytics workflows while preserving source integrity and documenting assumptions clearly.

## Quick start

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```

## Data source attribution

- Sales dataset: [1000 Sales Records](https://excelbianalytics.com/wp/downloads-18-sample-csv-files-data-sets-for-testing-sales/)
- Country metadata: [GeoNames countryInfo](https://download.geonames.org/export/dump/countryInfo.txt)
- Country alias mapping: project-provided metadata in `data/metadata/country_aliases.json`
